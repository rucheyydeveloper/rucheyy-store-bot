# Rucheyy Store | Developer v1.1

Versão simplificada para upload pelo celular.

Arquivos principais:
- `index.js`
- `package.json`
- `data/feedbacks.json`

Configure as variáveis de ambiente:
`DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID`, `SUPPORT_CATEGORY_ID`, `PRODUCT_CATEGORY_ID`, `STAFF_ROLE_ID`, `FEEDBACK_CHANNEL_ID`.

Comando de início: `npm start`
